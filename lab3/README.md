# Лабораторная работа №3

## Выполненные задания
В рамках лабораторной работы были реализованы следующие функции в файле `src/core.js`:
1. `isInteger` — проверка на целое число с помощью побитовых операторов.
2. `even` — генерация массива четных чисел от 2 до 20.
3. `sumTo` — сумма чисел до n с помощью цикла.
4. `recSumTo` — сумма чисел до n с помощью рекурсии.
5. `factorial` — вычисление факториала.
6. `isBinary` — проверка, является ли число степенью двойки.
7. `fibonacci` — нахождение N-го числа Фибоначчи.
8. `getOperationFn` — функция-замыкание для применения операции.
9. `sequence` — генератор арифметической последовательности.
10. `deepEqual` — рекурсивное глубокое сравнение объектов.
